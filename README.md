# SameDayDesk Agent Skill

Find and buy SameDayDesk services from your agent: free site checks, structured page data, website care and watch. The skill reads live prices and prepares the purchase. You approve and pay.

[Product](https://samedaydesk.com)

## Install

```sh
npx skills add epistemedeus/samedaydesk-skill --skill samedaydesk-machine-commerce --yes
```

Read [the installed skill](skills/samedaydesk-machine-commerce/SKILL.md) for its exact inputs and next action.
